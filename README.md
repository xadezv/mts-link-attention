# Контроль присутствия

Расширение для Chrome. На вебинарах МТС Линк и Webinar периодически всплывает
окно «Контроль присутствия» с кнопкой «Подтверждаю» и таймером. Расширение
жмёт её за вас или, если хотите жать сами, вовремя об этом сообщает.

## Установка

1. Скачать [zip последнего релиза](../../releases/latest) и распаковать в папку,
   которую не будете удалять — браузер грузит расширение прямо из неё.
2. Открыть `chrome://extensions`, включить «Режим разработчика» справа вверху.
3. «Загрузить распакованное расширение» → выбрать папку с `manifest.json`.
4. Обновить вкладку с вебинаром.

Для тех, кто не хочет читать: в архиве лежит `КАК УСТАНОВИТЬ.html`, открывается
двойным кликом.

Chrome, Edge, Яндекс, Opera.

## Как пользоваться

На странице вебинара в правом нижнем углу появляется зелёный кружок. Цифра на
нём — сколько раз подтвердил. Стал красным и мигает — окно висит прямо сейчас.
Клик открывает панель.

В панели два режима:

- **Жать само** — нажимает кнопку со случайной задержкой 1,5–5 секунд.
- **Только звать** — играет сигнал и присылает уведомление с кнопкой
  «Подтвердить». Нажать можно прямо из уведомления, переключаться на вкладку
  не нужно.

Ещё там:

- **Держать вкладку активной** — платформа не увидит, что вы свернули окно.
- **Форсить isFocused** — то же самое на уровне запроса, который шлёт плеер.
- **Жать «Огонёк» сам** — ставит реакцию через случайный промежуток,
  вилку задаёте сами. По умолчанию выключено.

Что показывает панель:

- `3 / 3 · 100%` — сколько показов окна отработано. Ровно это организатор видит
  в своём отчёте, так что пропущенный показ заметен сразу.
- Пинг присутствия: `12 с назад · 200`. Зелёное — сервер принял, красное —
  что-то не доехало.
- Последние события.

Если панели нет, всё то же самое лежит в попапе — иконка расширения в панели
браузера.

## Обновления

Расширение подтягивает из этого репозитория свежие настройки поиска при каждой
перезагрузке страницы. Когда платформа что-то меняет у себя, чинится на нашей
стороне — переустанавливать ничего не нужно.

Chrome умеет обновлять ещё и саму логику на лету, но для этого нужен тумблер
«Разрешить пользовательские скрипты» в карточке расширения (в Chrome до 138 —
Режим разработчика). Включать не обязательно: без него работает всё то же
самое, просто правки логики приедут со следующей версией, а не сразу.

Обновление самих файлов расширения приходит уведомлением со ссылкой — их
нужно переставить руками.
